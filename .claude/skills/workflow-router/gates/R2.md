# R2 Workflow — Medium Risk

## Workflow

1. S0：使用 bounded brainstorming 澄清 Goal/Scope/AC/Constraints。
2. S1：创建紧凑、唯一的规格产物；首选 OpenSpec，降级路径见 `v2/toolcheck.md`。
3. 计算并列出 required gates，补充对应验收和验证任务。
4. S3：形成实施步骤、依赖和测试策略。
5. Plan Review：首选 Plannotator；安全降级必须被记录。
6. S4：TDD 实施，保持改动边界。
7. S5：运行单元测试、构建和 required gates 的验证。
8. S6：首选 Plannotator Code Review；降级时 AI 自审并由用户过目 diff。
9. 记录 JSONL Metrics，按 CLAUDE.md 报告。

## Constraints

- 正式规格只有一处，Superpowers 不另建重复 plan/spec。
- 发现语义红旗、不可兼容契约、迁移或协调发布时立即重新评估。
