# R1 Workflow — Low Risk

## Entry

- baseline/final tier 为 R1，且无提升最低档位的语义红旗。
- 仍需叠加 `v2/gates.md` 中适用的门控。

## Fast Path

仅当 `.claude/project-profile.yaml` 允许，且同时满足以下条件时启用：

1. Score ≤2、单文件或等价局部范围。
2. 不改变运行时业务语义、公共契约、Schema、权限、基础设施默认值。
3. 有直接相关的快速验证方式且变更可轻易回滚。
4. 工作区没有与目标文件冲突的用户改动。

Fast Path 在宣布 Goal、Scope、简短计划和验证方式后可以直接执行，不等待单独的计划批准；完成后仍必须展示 diff、验证结果和风险。

## Regular Path

1. 明确 Goal + Scope，检查相关代码。
2. 给出简短计划并等待确认。
3. 实施最小安全改动。
4. 运行最相关的测试或检查。
5. AI 自审最终 diff，交用户过目。
6. 记录 JSONL Metrics，按 CLAUDE.md 报告。

## Constraints

- 不扩大需求范围。
- 条件失效时立即退出 Fast Path 并重新评估。
- 不以“位于高风险模块”单独升档，也不忽略实际语义风险。
