# L1 Workflow — Lightweight

## Suitable For

- 小型 Feature
- 多文件但局部影响
- 简单业务规则
- 低架构风险

## Workflow

1. Understand requirement.
2. Inspect relevant code and existing patterns.
3. Define a concise implementation plan.
4. Implement.
5. Run tests.
6. Inspect diff.
7. Self-review against acceptance criteria.
8. Report.

## Tooling

- Superpowers: use relevant lightweight workflow capabilities.
- Claude Code: implementation.
- OpenSpec: optional.
- Plannotator: optional.

## Constraints

不因为使用 L1 就自动创建完整规格文档。

如果探索过程中发现跨服务、数据迁移、核心业务一致性等风险，升级到 L2。
