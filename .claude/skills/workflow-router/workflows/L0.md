# L0 Workflow — Direct Execution

## Suitable For

- 明确的小 Bug
- 单点配置
- 文案
- 简单 SQL 修改
- 明确字段调整
- 单文件/极小范围修改
- 低风险任务

## Workflow

1. Understand the request.
2. Inspect only relevant code.
3. Implement the smallest safe change.
4. Run the most relevant tests/checks.
5. Inspect the final diff.
6. Report result.

## Constraints

- 不创建 OpenSpec Change。
- 不要求 Plan Review。
- 不要求 Plannotator。
- 不进行无必要的大范围重构。
- 不扩大需求范围。

## Completion

必须说明：

- Changed files
- Test/check result
- Remaining uncertainty
