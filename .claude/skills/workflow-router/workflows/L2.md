# L2 Workflow — Standard Engineering

## Suitable For

- 中型 Feature
- 跨模块需求
- 复杂业务规则
- 有明显数据或架构影响
- 中高风险业务

## Workflow

### 1. Understand

明确：

- Goal
- Scope
- Non-goals
- Acceptance Criteria
- Constraints

### 2. Superpowers

使用 Superpowers 的相关工作流完成需求分析、代码库探索、设计和规划。

### 3. OpenSpec

建立或更新对应 Change。

要求规格至少能够明确：

- Intent
- Scope
- Behavioral Requirements
- Design Decisions
- Implementation Tasks

OpenSpec 是本需求的 Specification Source of Truth。

### 4. Implementation Plan

生成可执行的实现计划：

- Task
- Files
- Dependencies
- Test Strategy
- Verification

### 5. Plan Review

通过 Plannotator 对计划进行人工 Review。

未通过不得进入实现阶段。

### 6. Implementation

使用 Claude Code + Superpowers 执行。

遵循项目现有架构和编码规范。

### 7. Verification

至少完成：

- Unit Test 或等价测试
- 相关集成测试（如果适用）
- Build
- Diff Review

### 8. Code Review

通过 Plannotator 对代码变更进行 Review。

### 9. Completion

输出：

- Final Level
- OpenSpec Change
- Changed Files
- Tests
- Verification
- Review Result
- Remaining Risks
